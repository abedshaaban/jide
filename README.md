# 记得 Jìde

Personal app for learning Mandarin Chinese: flashcards, pinyin, audio, notes, and spaced repetition.

- `ios/` — native iOS app (SwiftUI + SwiftData). Sideloaded with a free Apple developer account.
- `android/` — native Android app (Kotlin + Jetpack Compose). Comes later.
- `shared/data/` — word lists and dictionary data both apps bundle.
