# Shared data

Bundled by both apps. Regenerate with:

```sh
python3 -I shared/data/scripts/build_data.py            # downloads sources to $TMPDIR/jide-data-cache
python3 -I shared/data/scripts/build_data.py --cache DIR # reuse a download cache
```

## `words.json`

```jsonc
{
  "version": 4,
  "words": [{
    "rank": 1,                     // 1-based frequency rank (Wiktionary list order, duplicates removed)
    "simplified": "一",
    "traditional": "一",
    "pinyin": "yī",                // tone marks, one space between syllables
    "pinyinNumbered": "yi1",       // CC-CEDICT style: tone 1-5 (5 = neutral), "u:" = ü
    "gloss": "one",                // short Wiktionary gloss
    "definitions": ["one", "..."], // CC-CEDICT senses
    "hsk": 1,                      // HSK 2.0 level 1-6, or null
    "hsk3": 1,                     // HSK 3.0 level 1-7 (7 = 7-9), or null
    "sentences": [{ "id": 826049, "zh": "...", "pinyin": "wǒ zài jiā。", "en": "..." }] // Tatoeba, 0-3; pinyin one syllable per token
  }],
  "components": [{                 // character parts, ordered by rank
    "char": "扌",
    "rank": 2,                     // rank of the first word that uses it: teach it right before that word
    "pinyinNumbered": "shou3",     // "" when the part has no reading
    "definition": "hand",          // Make Me a Hanzi; senses separated by ";"
    "isWord": false,               // true: already in "words" (女, 口), do not create a second entry
    "count": 71,                   // characters of the word list that contain it
    "usedIn": ["在", "把"]         // up to 8 of those characters, in word-frequency order
  }]
}
```

3,000 words. The list comes from a Taiwanese corpus, so a few local institution names are skipped
(`SKIP_WORDS` in the script).

Components are the parts of the words' characters and the parts of those parts (想 → 相 心 → 木 目),
kept when they have a meaning, are more than a single stroke and appear in at least 3 characters.
Apps store a part that is not a word as a word with ID `cmp:<char>` and a single 汉字 → meaning card,
and show the "Character parts" deck from every `components` entry (`cmp:<char>`, or `zh:<char>` when
`isWord`).

Sentence pinyin is generated by greedy dictionary segmentation, so it can be wrong for
polyphonic characters.

## `characters.json`

```jsonc
{
  "version": 3,
  "characters": {
    "你": {
      "definition": "you, second person pronoun",
      "pinyin": ["nǐ"],
      "decomposition": "⿰亻尔",     // Ideographic Description Sequence, "？" = unknown
      "radical": "亻",
      "etymology": { "type": "ideographic", "hint": "..." },  // optional
      "strokes": ["M 323 706 Q ..."],  // SVG paths, 1024x1024 box, y-up (flip: y' = 900 - y)
      "medians": [[[336, 704], ...]]   // stroke centre lines, same coordinates
    }
  }
}
```

All 9,574 Make Me a Hanzi characters have an entry (pinyin, meaning, decomposition) so custom
words get pinyin guesses and breakdowns. Stroke data is included only for characters used by the
bundled words and for the components.
