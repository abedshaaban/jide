# Shared data

Bundled by both apps. Regenerate with:

```sh
python3 -I shared/data/scripts/build_data.py            # downloads sources to $TMPDIR/jide-data-cache
python3 -I shared/data/scripts/build_data.py --cache DIR # reuse a download cache
```

## `words.json`

```jsonc
{
  "version": 2,
  "words": [{
    "rank": 1,                     // 1-based frequency rank (Wiktionary list order, duplicates removed)
    "simplified": "一",
    "traditional": "一",
    "pinyin": "yī",                // tone marks, one space between syllables
    "pinyinNumbered": "yi1",       // CC-CEDICT style: tone 1-5 (5 = neutral), "u:" = ü
    "gloss": "one",                // short Wiktionary gloss
    "definitions": ["one", "..."], // CC-CEDICT senses
    "hsk": 1,                      // HSK 2.0 level 1-6, or null
    "hsk3": 1,                     // HSK 3.0 level 1-7 (7 = 7-9), or null
    "sentences": [{ "id": 826049, "zh": "...", "pinyin": "wǒ zài jiā。", "en": "..." }] // Tatoeba, 0-3; pinyin one syllable per token
  }]
}
```

Sentence pinyin is generated by greedy dictionary segmentation, so it can be wrong for
polyphonic characters.

## `characters.json`

```jsonc
{
  "version": 2,
  "characters": {
    "你": {
      "definition": "you, second person pronoun",
      "pinyin": ["nǐ"],
      "decomposition": "⿰亻尔",     // Ideographic Description Sequence, "？" = unknown
      "radical": "亻",
      "etymology": { "type": "ideographic", "hint": "..." },  // optional
      "strokes": ["M 323 706 Q ..."],  // SVG paths, 1024x1024 box, y-up (flip: y' = 900 - y)
      "medians": [[[336, 704], ...]]   // stroke centre lines, same coordinates
    }
  }
}
```

Every character of every word has an entry when Make Me a Hanzi covers it; components
reached through decompositions are included without stroke data.
